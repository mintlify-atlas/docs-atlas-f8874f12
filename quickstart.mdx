## Prerequisites

Before you start, make sure you have:

- **Node.js 20+**
- **React 19+**
- **Vite 8+**

## Option 1: Scaffold with create-devix

The fastest way to get started is with the `create-devix` scaffolding tool. It creates a new project with the correct structure, dependencies, and configuration already in place.

<Steps>
  <Step title="Create a new project">
    Run the scaffolder and follow the prompt to name your project:

    ```bash
    npx create-devix my-app
    ```

    You can also pass the project name directly as an argument. If the directory already exists, the tool will ask before overwriting.
  </Step>

  <Step title="Install dependencies">
    ```bash
    cd my-app
    npm install
    ```
  </Step>

  <Step title="Start the development server">
    ```bash
    npm run dev
    ```

    Open [http://localhost:3000](http://localhost:3000). The page is server-rendered and automatically hydrated on the client.
  </Step>
</Steps>

## Option 2: Manual installation

<Steps>
  <Step title="Install dependencies">
    Install devix and its peer dependencies:

    <CodeGroup>

    ```bash npm
    npm install @devlusoft/devix react react-dom
    ```

    ```bash yarn
    yarn add @devlusoft/devix react react-dom
    ```

    ```bash pnpm
    pnpm add @devlusoft/devix react react-dom
    ```

    </CodeGroup>

    Also install the dev dependencies:

    <CodeGroup>

    ```bash npm
    npm install -D @types/react @types/react-dom typescript vite
    ```

    ```bash yarn
    yarn add -D @types/react @types/react-dom typescript vite
    ```

    ```bash pnpm
    pnpm add -D @types/react @types/react-dom typescript vite
    ```

    </CodeGroup>
  </Step>

  <Step title="Create devix.config.ts">
    Create a `devix.config.ts` file at the root of your project:

    ```ts devix.config.ts
    import { defineConfig } from '@devlusoft/devix/config'

    export default defineConfig({
      port: 3000,
    })
    ```

    <Note>
      You do not need a `vite.config.ts`. Use the `vite` field inside `devix.config.ts` to extend Vite configuration.
    </Note>
  </Step>

  <Step title="Configure TypeScript">
    Create a `tsconfig.json` at the root of your project:

    ```json tsconfig.json
    {
      "compilerOptions": {
        "target": "ESNext",
        "module": "ESNext",
        "moduleResolution": "bundler",
        "jsx": "react-jsx",
        "strict": true,
        "lib": ["ESNext", "DOM"]
      },
      "include": ["app", "devix.config.ts", ".devix"]
    }
    ```
  </Step>

  <Step title="Create your first page">
    Create the file `app/pages/index.tsx`:

    ```tsx app/pages/index.tsx
    import type { Metadata } from '@devlusoft/devix'

    export const metadata: Metadata = {
      title: 'My devix app',
      description: 'Built with devix',
    }

    export default function Home() {
      return (
        <main>
          <h1>Hello devix!</h1>
          <p>Edit <code>app/pages/index.tsx</code> to get started.</p>
        </main>
      )
    }
    ```

    <Tip>
      Every file in `app/pages/` automatically becomes a route. `index.tsx` maps to `/`.
    </Tip>
  </Step>

  <Step title="Add scripts to package.json">
    Add the devix CLI commands to your `package.json`:

    ```json package.json
    {
      "scripts": {
        "dev": "devix dev",
        "build": "devix build",
        "start": "devix start",
        "generate": "devix generate"
      }
    }
    ```
  </Step>

  <Step title="Start the development server">
    ```bash
    npx devix dev
    ```

    Open [http://localhost:3000](http://localhost:3000). Every page is server-rendered and automatically hydrated on the client.
  </Step>
</Steps>

## CLI commands

| Command | Description |
|---|---|
| `devix dev` | Start the development server with HMR |
| `devix build` | Build for production |
| `devix start` | Start the production server |
| `devix generate` | Build and pre-render all pages (SSG) |

## Building for production

To build and run your app in production:

```bash
npx devix build
npx devix start
```

For static site generation (SSG), set `output: 'static'` in your config and use `devix generate` instead:

```ts devix.config.ts
import { defineConfig } from '@devlusoft/devix/config'

export default defineConfig({
  output: 'static',
})
```

```bash
npx devix generate
npx devix start
```

<Note>
  In `static` output mode, `devix start` serves pre-rendered static files without any runtime SSR.
</Note>

## Extending Vite

Pass any Vite configuration through the `vite` field in `devix.config.ts`:

```ts devix.config.ts
import { defineConfig } from '@devlusoft/devix/config'

export default defineConfig({
  vite: {
    resolve: {
      alias: { '@': '/app' },
    },
  },
})
```
